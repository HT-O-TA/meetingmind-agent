## 三、结果分析

### 核心问题
1. **精确率极低 (15.8%)** — 最核心问题
   - 原因：TOP_K=2 时，精确率 = 命中数/2。15.8% 意味着平均每2个结果只有约0.316个相关结果
   - 根本原因：检索质量本身不足——相似度阈值 0.7 太低，导致不相关文档混入

2. **MRR 偏低 (0.4414)**
   - 相关文档往往不在第1位返回，说明排序质量差

3. **答案相似度和上下文相关性双低**
   - LLM 上下文被限制在 3000 字符，TOP_K=2 的情况下若检索结果不准，LLM 无有效信息可用

4. **速度过慢 (10.26s/题)**
   - 主要瓶颈：lightweight 模式遍历全库所有 chunk（O(n) 复杂度）、LLM API 调用延迟、Embedding 模型推理时间（未批量化）
