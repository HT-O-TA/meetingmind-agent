🎯 拓展规划（按优先级）

第1-2周：提示工程全栈

学习内容 具体行动 产出/成果
提示工程全栈 1. 学习CoT（思维链）、ReAct（思考-行动-观察）、Self-Consistency、Few-shot等技巧
2. 掌握结构化输出（JSON mode）
3. 优化现有Agent的prompt模板
4. 为不同任务（会议纪要、待办提取、争议分析）设计专门的prompt
5. 建立prompt版本管理和A/B测试机制		 1. 在MeetingMind项目中对3个核心任务（会议问答、纪要生成、待办提取）各设计3版Prompt，对比效果
2. 输出一份《MeetingMind Prompt优化笔记》，包含不同策略的效果对比
3. 实现结构化输出的JSON schema验证机制

第3周：DSPy + Prompt测评

学习内容 具体行动 产出/成果
DSPy + Prompt测评 1. 学习DSPy自动优化提示
2. 用PromptFoo或Ragas评估Prompt效果（准确率、稳定性）
3. 设计DSPy Signatures定义核心任务
4. 用DSPy的Compile功能优化现有模块		 1. 跑通DSPy优化一个简单任务（如：会议摘要生成）
2. 输出《Prompt测评报告》，包含不同Prompt策略的准确率、召回率、稳定性对比
3. 在项目中集成DSPy模块，支持自动优化

第4-5周：Elasticsearch

学习内容 具体行动 产出/成果
Elasticsearch 1. 学习ES全文检索、分词器、过滤器
2. 对比ES与向量库的适用场景
3. 在本地搭建Elasticsearch集群
4. 将会议文档索引到ES
5. 实现混合检索（ES BM25 + 向量检索 + Reranker）		 1. 用ES替代单纯向量检索，做混合检索实验
2. 输出《检索效果对比报告》，对比召回率、准确率、响应时间
3. 在项目中实现ES检索模块，可配置启用/禁用

第6周：Neo4j知识图谱升级

学习内容 具体行动 产出/成果
Neo4j知识图谱 1. 学习Cypher查询语言
2. 从会议文档中抽取实体关系，构建小知识图谱
3. 将现有的内存实现迁移到Neo4j
4. 设计图谱查询策略，增强检索上下文		 1. 实现一个简单问答："张三参与的会议有哪些？"通过图谱推理
2. 输出《知识图谱增强效果报告》，对比有无图谱的检索效果
3. 在项目中集成Neo4j作为可选知识图谱后端

第7-8周：微调理论 + 数据工程

学习内容 具体行动 产出/成果
微调理论 + 数据工程 1. 学习SFT（监督微调）、LoRA原理
2. 准备一个领域数据集（会议摘要数据）
3. 设计数据标注规范
4. 构建高质量微调数据集（500条指令数据）		 1. 整理出500条高质量指令微调数据（从会议库中提取）
2. 输出《数据标注规范》和《数据集质量报告》
3. 建立数据版本管理机制

第9-10周：LoRA微调实践

学习内容 具体行动 产出/成果

2. 在会议总结任务上测试微调效果
3. 对比微调前后的生成质量
4. 用Ragas评估微调效果		 1. 输出LoRA适配器权重文件（可开源分享）
