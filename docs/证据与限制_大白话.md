# 证据与限制（大白话）

## 已经有证据的内容

- 输入契约、权限越界、直接注入拒绝、间接注入隔离：有 `backend/tests/contracts/` 契约测试。
- 上下文优先级、精确去重、截断、同文档数量限制和 `ContextManifest`：有上下文组装契约测试。
- PostgreSQL、Redis、RabbitMQ 的部分真实集成：有 `backend/tests/integration/` 测试和固定脚本。
- WAV 文件准入、FunASR Worker 和证据生命周期：有 ASR 合同、队列烟测和公开样例报告。
- LoRA/QLoRA：有真实单卡运行报告，但训练和测试数据是项目自编合成数据。
- Prompt Injection：有冻结的 25 条合成回归集，并进入 CI。
- 规划层 P0 门禁：有计划结构、工具白名单、依赖循环、约束阈值和熔断的契约测试；真实长任务效果仍未验证。

## 还没有形成的证据

- 真实或脱敏长会议上的上下文参数基线；
- 真实会议的 RAG 召回、引用覆盖率和任务完成率；
- 真实多人会议的 ASR CER/DER；
- 真实攻击分布下的 Prompt Injection 误报和漏报；
- 多节点 RabbitMQ 高可用和生产容量；
- 真实 Jira 站点写入、回查和权限演示。

## 本轮新增的可复核材料

- 已建立 `backend/evaluation/datasets/meetingmind_deidentified_v1.jsonl`（8 条项目自编脱敏样例）并生成离线报告。报告里的 Recall@K、MRR、引用正确率和待办 F1 只说明评测链路可用，不说明真实会议泛化效果。
- 已审查本地 AliMeeting Eval 和 VCSUM，并完成 580 个单元的独立 AI 第一轮复核：问答 158 条、待办 194 条、约束 228 条。问答引用由 1,045 个候选引用补全为 3,409 个上游证据项；待办保留并规范 10 条、拒绝 184 条；约束保留 71 条、拒绝 157 条。状态仍为 `ai_reviewed_silver`，必须完成人工抽检后才能进入正式评测。
- 已提供 `scripts/measure_agent_runtime.py`，可对真实 API 记录 P50/P95、失败率、Token 和成本。由于本轮没有启动线上服务、真实模型账单和价格参数，P50/P95 与单请求成本仍待实测。
- 已提供 [固定五分钟演示](./固定五分钟演示_大白话.md)，其中工具确认是策略门禁证据，HTTP/队列是否通过取决于本地依赖服务状态。

## 读报告时要注意

“测试通过”通常只说明代码契约成立，不说明模型效果已经很好。

特别是：

- 合成 Prompt Injection 报告不能代表生产安全率；
- 合成 LoRA F1 不能代表真实会议待办抽取质量；
- 公开单句 ASR 烟测不能代表多人长会议识别质量；
- 本机 Docker Compose 通过不能代表生产高可用。

## 本项目当前最诚实的说法

这是一个已经收敛到真实主链路的 AI 应用工程项目：RAG、Agent、权限、安全工具调用、异步任务和 ASR 证据链都已有代码和部分验证；离线脱敏评测和固定演示入口已经建立，但真实业务数据上的最终效果、线上 P50/P95/成本和生产级基础设施能力仍待补证。
