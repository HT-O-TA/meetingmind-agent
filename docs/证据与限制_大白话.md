# 证据与限制（大白话）

## 已经有证据的内容

- 输入契约、权限越界、直接注入拒绝、间接注入隔离：有 `backend/tests/contracts/` 契约测试。
- 上下文优先级、精确去重、截断、同文档数量限制和 `ContextManifest`：有上下文组装契约测试。
- PostgreSQL、Redis、RabbitMQ 的部分真实集成：有 `backend/tests/integration/` 测试和固定脚本。
- WAV 文件准入、FunASR Worker 和证据生命周期：有 ASR 合同、队列烟测和公开样例报告。
- LoRA/QLoRA：有真实单卡运行报告，但训练和测试数据是项目自编合成数据。
- Prompt Injection：有冻结的 25 条合成回归集，并进入 CI。

## 还没有形成的证据

- 真实或脱敏长会议上的上下文参数基线；
- 真实会议的 RAG 召回、引用覆盖率和任务完成率；
- 真实多人会议的 ASR CER/DER；
- 真实攻击分布下的 Prompt Injection 误报和漏报；
- 多节点 RabbitMQ 高可用和生产容量；
- 真实 Jira 站点写入、回查和权限演示。

## 读报告时要注意

“测试通过”通常只说明代码契约成立，不说明模型效果已经很好。

特别是：

- 合成 Prompt Injection 报告不能代表生产安全率；
- 合成 LoRA F1 不能代表真实会议待办抽取质量；
- 公开单句 ASR 烟测不能代表多人长会议识别质量；
- 本机 Docker Compose 通过不能代表生产高可用。

## 本项目当前最诚实的说法

这是一个已经收敛到真实主链路的 AI 应用工程项目：RAG、Agent、权限、安全工具调用、异步任务和 ASR 证据链都已有代码和部分验证；真实业务数据上的最终效果和生产级基础设施能力仍待补证。
