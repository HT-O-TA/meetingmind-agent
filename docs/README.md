## 当前边界

- 真实评测集为 28 场会议、100 条人工复核任务，不是 100 场会议。
- QA 检索实验属于已知会议范围内的排序实验，不代表全库检索效果。
- 待办和约束指标属于候选保留与字段规范化，不是整场会议端到端抽取 F1。
- Jira 只保留受控工具接入边界，没有完成真实企业站点写入验收。
- 长期记忆以 PostgreSQL 为权威源；Milvus/Neo4j 记忆投影器尚未完整启用。
- 项目已验证本地工程闭环，不声称生产级高可用、泛化能力或企业上线经验。
