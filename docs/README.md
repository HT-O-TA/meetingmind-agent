# MeetingMind 文档入口

这份目录以前有不少“阶段记录”和“设计版本”，内容容易重复。现在统一按下面的方式阅读：先看大白话主文档，再按需要看技术细节和历史证据。

## 先看当前口径

1. [项目总览（大白话）](./项目总览_大白话.md)

   用几页内容说明项目做什么、请求怎么流转、每个模块在哪里、哪些能力已经验证、哪些还不能对外宣称。

2. [输入预处理层技术说明](./架构解析/输入预处理层.md)

   这里说明 `InputEnvelope`、`TaskAnchor`、上下文预算和进入记忆层前的边界。当前是否完成，以代码、契约测试和真实长会议复核结果为准。

3. [证据与限制（大白话）](./证据与限制_大白话.md)

   说明哪些测试是真实基础设施验证，哪些只是契约测试或合成数据，避免把 Demo 结果误说成生产效果。

4. [当前状态与下一步（大白话）](./当前状态与下一步_大白话.md)

   记录输入层、规划层、记忆层目前做到哪里，以及为什么要先整理文档、补真实证据和固定演示，再继续翻新其他层。

5. [文档治理清单（大白话）](./文档治理清单_大白话.md)

   说明哪些是当前口径、哪些是历史记录、哪些是旧格式材料，以及发现过哪些内容冲突。

6. [固定五分钟演示（大白话）](./固定五分钟演示_大白话.md)

   说明如何一次跑通正常路径、权限拒绝、工具确认和队列恢复，并保存可复核证据。

## 历史阶段记录

`优化路径记录/01` 到 `13` 是按时间保存的决策和实现证据，不是新的功能清单。阅读时以“项目总览”和“第三版”为准，阶段记录只在需要追溯“为什么这样改”时查看。

第一版、第二版六链路设计也保留作历史对照；第三版是当前口径。它们没有直接删除，因为其中包含取舍原因和学习检查点，不应被误当成当前待办。
