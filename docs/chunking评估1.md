# 2×3 因子实验方案与结果报告

---

## 一、实验方案

### 1.1 实验因子与水平

| 因子 | 水平 | 说明 |
|------|------|------|
| **A: 过滤预处理** | A1: 无过滤 | 保留所有原始行（包括语气词行、短行） |
|                  | A2: 有过滤 | 删除纯语气词行及长度 < 3 的行 |
| **B: 分块策略** | B1: 固定大小分块 | 滑动窗口（chunk_size=512, overlap=64） |
|                  | B2: 混合相似度分块 | 基于TF-IDF余弦相似度合并（阈值0.6，最大块长800） |
|                  | B3: 说话人切割分块 | 按说话人切换切分，块内只存纯文本 |

**共6个实验组**：A1B1, A1B2, A1B3, A2B1, A2B2, A2B3

### 1.2 数据预处理流程

**原始数据格式**：`[时间] 说话人: 内容`

**提取三要素**：
- `timestamp`：如 `01:22.53`
- `speaker`：如 `8013`
- `content`：冒号后面的文本

**输入格式构造**：

| 策略 | 输入格式 | 构造方式 |
|------|----------|----------|
| B1, B2 | 纯文本内容（无标签） | 所有行的`content`按原序用`\n`连接 |
| B3 | 带标签的行列表 | 保留`(speaker, content)`元组 |

**过滤规则（A2组）**：
- 长度 < 3 的行丢弃
- 匹配语气词正则的行丢弃：`^(嗯|啊|哦|唉|对|好|是|呃|哎|额|行|嗯哼|啊哈|对对对|嗯嗯|嗯嗯嗯)+[。！？]*$`

### 1.3 分块策略实现

**B1: 固定大小分块**

**B2: 混合相似度分块**
1. 按空行或换行拆分为初始段落
2. 计算相邻段落TF-IDF余弦相似度
3. 相似度≥0.6且合并后长度≤800则合并

**B3: 说话人切割分块**
1. 遍历`(speaker, content)`列表
2. 说话人变化时切分块
3. 单块超过1000字符时二次分割

### 1.4 评价指标

| 指标 | 计算方法 |
|------|----------|
| 块数 | 输出块列表长度 |
| 平均块大小 | 所有块长度的均值 |
| 块大小标准差 | 各块长度的标准差 |
| 噪音块率 | 块内容完全由语气词构成的比例 |
| 平均说话人切换 | 块内不同说话人次数的均值（B1/B2为N/A） |
| 有效信息密度 | 块中非语气词字符数 / 总字符数 |
| 语义完整性 | 块以标点结尾+块长适中(50-1000字符+无不完整结尾标志(的/是/我觉得得结尾) 得分 |
| 处理时间 | 分块耗时 / 输入总字符数 × 1000（ms/k字符） |

## 三、结果分析

### 3.1 优化效果对比

| 策略 | 块数变化 | 语义完整性变化 | 噪音块率变化 | 说明 |
|------|----------|---------------|--------------|------|
| B1 | -14.5% | +0.25（0.35→0.60） | 保持0% | 语义锚点切分有效 |
| B2 | -34.3% | -0.28（0.49→0.21） | 从22%降至6% | 策略特性：优先语义连贯而非句子完整 |
| B3 | -65.8% | +0.12（0.54→0.66） | 从5%降至0% | 优化效果最佳 |

### 3.2 各策略优化前后对比

**B1（固定大小分块）**：
- 优化后块数减少14.5%，平均块大小略降但语义完整性大幅提升（+0.25）
- 语义锚点切分有效保留了句子完整性，从0.35提升至0.60
- 注：优化后语义完整性（0.60）仍然偏低，可能因为很多会议短句不以标准标点结尾

**B2（相似度分块）**：
- 优化后块数显著减少（-34.3%），平均块大小从16字符提升至22字符，噪音块率从22%降至6%
- **语义完整性从0.49降至0.21**：这是预期现象，因为B2优化使用语义相似度合并相邻段落，优先保证语义连贯性而非句子完整性，导致合并后块内可能包含多个句子，且不以完整标点结尾，完整性得分降低

**B3（说话人切割分块）**：
- 优化效果最显著：块数减少65.8%，平均块大小从46字符提升至115字符
- 语义完整性最高（0.54→0.66），噪音块率降至0%

### 3.3 各策略特点总结

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| B1 | 稳定、快速、可控、噪音为0 | 语义完整性中等 | 需要固定块大小的场景 |
| B2 | 细粒度、语义连贯 | 计算慢、块小、语义完整性低 | 需要语义相关性的场景 |
| B3 | 说话人单一、语义完整性最高、噪音为0 | 块大小不均 | 需要保持说话人完整性的场景 |

## 四、结论

1. **B3说话人切割策略优化效果最显著**：块数减少65.8%，平均块大小从46字符提升至115字符，语义完整性最高（0.66），噪音块率降至0%，是三种策略中综合表现最优的方案。

2. **B1固定大小分块稳定可靠**：优化后语义完整性从0.35提升至0.60，噪音块率保持0%，处理速度最快，适合需要均匀块大小的场景。

3. **B2相似度分块策略特性分析**：语义完整性下降（0.49→0.21）是预期现象，该策略优先保证语义连贯性而非句子完整性，适合对语义相关性要求较高的场景。

4. **语义锚点切分有效提升块质量**：B1优化版通过寻找句子边界切分，在保持块大小稳定的同时提升了语义完整性。

5. **过滤预处理有效提升数据质量**：去除语气词和短行后，有效信息密度从0.80-0.86提升至0.88-0.92，噪音块率显著降低。
