## 三、评估指标

### 3.1 检索指标

#### 3.1.1 Recall@k（召回率）
**定义**：检索到的相关文档数与总相关文档数的比值。
**意义**：衡量系统找到所有相关信息的能力。

#### 3.1.2 Precision@k（精确率）
**定义**：检索到的相关文档数与检索结果总数的比值。
**意义**：衡量系统只返回相关信息的能力。

#### 3.1.3 MRR（Mean Reciprocal Rank）
**定义**：首次命中相关文档位置的倒数的平均值。
**意义**：衡量相关文档在检索结果中的排名位置。

### 3.2 生成指标

#### 3.2.1 Answer Similarity（答案相似度）
**定义**：生成答案与标准答案的相似度。
**意义**：衡量生成答案与标准答案的匹配程度。

### 3.3 RAGAS指标（新增）

| 指标 | 说明 | 范围 |
|------|------|------|
| faithfulness | 答案忠实度，衡量答案是否基于检索内容 | 0-1 |
| relevancy | 相关性，衡量检索内容与问题的相关性 | 0-1 |
| precision | 精确率，衡量答案中有用信息的比例 | 0-1 |
| recall | 召回率，衡量答案覆盖问题要点的程度 | 0-1 |
| answer_relevancy | 答案相关性，衡量答案与问题的相关性 | 0-1 |
| context_recall | 上下文召回率，衡量上下文覆盖答案的程度 | 0-1 |

## 四、检索策略说明

### 4.1 当前检索架构

```
查询 → 三路召回 → RRF融合 → Reranker精排 → 最终结果
```

### 4.2 三路召回策略

| 召回方式 | 说明 | 模型/算法 |
|---------|------|----------|
| BM25 | 传统关键词检索 | BM25F字段加权 |
| BGE-M3稠密 | 语义向量检索 | BGE-M3 dense向量 |
| BGE-M3稀疏 | 稀疏向量检索 | BGE-M3 lexical_weights |

### 4.3 融合策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| **策略A** | 加权融合 | 简单场景，计算效率高 |
| **策略B（默认）** | RRF融合（k=60） | 复杂场景，效果更优 |

### 4.4 Reranker精排

- **模型**：BGE-Reranker-v2-m3
- **候选数**：RRF融合后取Top-N进入精排
- **作用**：对召回结果进行重排序，提升精确率

## 五、切分模式对比

### 5.1 模式说明

| 模式 | 说明 | 优势 | 适用场景 |
|------|------|------|----------|
| `speaker` | 按说话人发言切分（SPEAKER_AWARE_HYBRID策略） | 语义完整性高、可追溯发言来源 | 会议记录、对话文本 |
| `fixed` | 固定长度切分 | 处理速度快、兼容性强 | 普通文档、知识库 |
| `semantic` | 语义相似度分块 | 保持语义完整性 | 长文档、技术文档 |

### 5.2 自动回退机制
系统具备智能识别能力：
- 当文档包含说话人信息时 → 自动使用 `speaker` 模式
- 当文档不包含说话人信息时 → 自动降级为纯语义分块（SEMANTIC_HYBRID）

## 六、自适应推理路由（新增）

### 6.1 四级复杂度分级

| 级别 | 范围 | 特点 | 处理方式 |
|------|------|------|----------|
| **S (Simple)** | 0.0-0.3 | 单事实、无需检索、无推理 | 直接Simple QA |
| **R (Retrieval)** | 0.3-0.5 | 事实型、简单，但必须查资料 | RAG单轮检索 |
| **C (CoT)** | 0.5-0.75 | 需要1-2步推理，不一定需要工具 | CoT + 可选轻量检索 |
| **A (Agent/ReAct)** | 0.75-1.0 | 多跳、多源、需要多轮推理+工具 | ReAct循环 |

### 6.2 Plan模式
- **触发条件**：检测到多子任务/多目标/需要拆解的问题
- **处理流程**：Plan分解 → 子任务路由（子任务走S/R/C/A）→ 结果汇总

### 6.3 策略回退机制
- ReAct失败 → 降级到CoT
- CoT失败 → 降级到RAG
- 检测连续相同输出 → 自动切换规则路由

## 七、核心配置参数

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| `TOP_K_DEFAULT` | 5 | 系统默认检索返回结果数量 |
| `EVAL_TOP_K` | 5 | 评估时检索返回结果数量，覆盖 `TOP_K_DEFAULT` |
| `SIMILARITY_THRESHOLD` | 0.7 | 相似度阈值 |
| `CHUNK_SIZE` | 512 | 文本切片大小（fixed模式） |
| `CHUNK_OVERLAP` | 64 | 切片重叠大小（fixed模式） |
| `CHUNK_MODE` | `"speaker"` | 切分模式：`"speaker"`/`"fixed"`/`"semantic"` |
| `ENABLE_MULTI_RETRIEVAL` | `true` | 是否启用多路召回 |
| `ENABLE_BM25` | `true` | 是否启用BM25检索 |
| `ENABLE_RERANK` | `true` | 是否启用重排序 |
| `RETRIEVAL_STRATEGY` | `"B"` | 检索策略：`"A"`(加权融合)或`"B"`(RRF融合) |
| `RRF_K` | 60 | RRF融合参数 |
| `RERANK_TOP_N` | 20 | Reranker候选数 |
| `COMPLEXITY_THRESHOLD_S` | 0.3 | Simple级别阈值 |
| `COMPLEXITY_THRESHOLD_R` | 0.5 | Retrieval级别阈值 |
| `COMPLEXITY_THRESHOLD_C` | 0.75 | CoT级别阈值 |

## 八、评估流程

1. **数据准备**：将测试文档上传至数据库（217篇会议文档）
2. **向量化**：系统自动对文档进行切片和向量化（支持BGE-M3稠密+稀疏向量）
3. **评估执行**：遍历问题，执行检索；默认 `EVAL_SKIP_LLM=True` 时只计算检索指标，需要生成指标时可关闭该开关
4. **指标计算**：计算各项评估指标（Recall@k、Precision@k、MRR、RAGAS指标）
5. **结果分析**：统计分析并输出评估报告

## 十一、性能指标

### 11.1 响应时间
- **检索耗时**：50-100ms（三路召回+RRF融合）
- **Reranker耗时**：30-50ms
- **LLM生成耗时**：200-500ms（取决于输出长度）

### 11.2 资源使用
- **BGE-M3模型**：约2.2GB（FP16）
- **Reranker模型**：约1.5GB
- **GPU显存**：建议≥8GB
