## 三、评估指标

### 3.1 检索指标

#### 3.1.1 Recall@k（召回率）
**定义**：检索到的相关文档数与总相关文档数的比值。
**意义**：衡量系统找到所有相关信息的能力。

#### 3.1.2 Precision@k（精确率）
**定义**：检索到的相关文档数与检索结果总数的比值。
**意义**：衡量系统只返回相关信息的能力。

#### 3.1.3 MRR（Mean Reciprocal Rank）
**定义**：首次命中相关文档位置的倒数的平均值。
**意义**：衡量相关文档在检索结果中的排名位置。

### 3.2 生成指标

#### 3.2.1 Answer Similarity（答案相似度）
**定义**：生成答案与标准答案的相似度。
**意义**：衡量生成答案与标准答案的匹配程度。

## 四、切分模式对比

### 4.1 模式说明

| 模式 | 说明 | 优势 | 适用场景 |
|------|------|------|----------|
| `speaker` | 按说话人发言切分 | 语义完整性高、可追溯发言来源 | 会议记录、对话文本 |
| `fixed` | 固定长度切分 | 处理速度快、兼容性强 | 普通文档、知识库 |

### 4.2 自动回退机制
系统具备智能识别能力：
- 当文档包含说话人信息时 → 自动使用 `speaker` 模式
- 当文档不包含说话人信息时 → 自动回退到 `fixed` 模式

## 五、核心配置参数

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| `TOP_K_DEFAULT` | 5 | 系统默认检索返回结果数量 |
| `EVAL_TOP_K` | 5 | 评估时检索返回结果数量，覆盖 `TOP_K_DEFAULT` |
| `SIMILARITY_THRESHOLD` | 0.7 | 相似度阈值 |
| `CHUNK_SIZE` | 512 | 文本切片大小（fixed模式） |
| `CHUNK_OVERLAP` | 64 | 切片重叠大小（fixed模式） |
| `CHUNK_MODE` | `"speaker"` | 切分模式：`"speaker"`或`"fixed"` |
| `ENABLE_MULTI_RETRIEVAL` | `true` | 是否启用多路召回 |
| `ENABLE_BM25` | `true` | 是否启用BM25检索 |
| `ENABLE_RERANK` | `true` | 是否启用重排序 |

## 六、评估流程

1. **数据准备**：将测试文档上传至数据库
2. **向量化**：系统自动对文档进行切片和向量化
3. **评估执行**：遍历问题，执行检索；默认 `EVAL_SKIP_LLM=True` 时只计算检索指标，需要生成指标时可关闭该开关
4. **指标计算**：计算各项评估指标
5. **结果分析**：统计分析并输出评估报告
