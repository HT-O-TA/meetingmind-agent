# MeetingMind 项目目录总览（冻结版）

这份文档只回答一个问题：每个目录和文件是干什么的。学习时不需要逐个打开全部文件，先按“必须掌握 / 需要知道 / 可以跳过”分类。

## 一、最重要的主链

一次用户请求大致经过：

```text
API 请求
  → 输入预处理与安全检查
  → 意图路由与规划
  → 会议检索 / 记忆读取
  → Agent 工具执行
  → 结构化输出与引用
  → 审计、队列和失败恢复
```

| 路径 | 定位 | 重要程度 |
|---|---|---|
| `backend/app/api/` | FastAPI 路由，接收请求并返回结果 | 必须掌握 |
| `backend/app/schemas/` | 请求、响应和 Agent 状态的数据结构 | 必须掌握 |
| `backend/app/agents/state.py` | Agent 全局状态、任务类型、风险等级 | 必须掌握 |
| `backend/app/agents/graph.py` | LangGraph 节点和执行顺序 | 必须掌握 |
| `backend/app/agents/nodes.py` | 输入、路由、规划、检索、工具、校验、反思等节点实现 | 必须掌握核心函数 |
| `backend/app/agents/agent_service.py` | Agent 对外服务入口和运行编排 | 必须掌握 |
| `backend/app/services/input_preprocessor.py` | 输入封装、TaskAnchor、注入和上下文污染防护 | 必须掌握 |
| `backend/app/services/intent_router.py` | 根据问题选择 QA、待办、纪要或复杂任务 | 必须掌握 |
| `backend/app/services/context_assembler.py` | 组织输入、记忆、检索证据和工具结果 | 必须掌握 |
| `backend/app/services/vector_search_service.py` | 会议片段检索、ACL 过滤、引用信息整理 | 必须掌握 |
| `backend/app/services/embedding_service.py` | 文本向量化和向量写入 | 需要掌握 |
| `backend/app/services/memory_service.py` | 短期/长期记忆读写、命名空间和冲突处理 | 必须掌握 |
| `backend/app/agents/tools/` | 工具注册、选择、参数检查和风险控制 | 必须掌握 |
| `backend/app/agents/human_in_the_loop.py` | 高风险动作人工确认 | 必须掌握 |
| `backend/app/services/structured_output_service.py` | JSON 解析、修复和输出校验 | 必须掌握 |
| `backend/app/workers/` | RabbitMQ/后台任务消费者和失败重试 | 需要掌握 |

## 五、可以暂时跳过的部分

| 路径/内容 | 原因 |
|---|---|
| `frontend/src/` 的页面样式、HTML 布局、组件美化 | 不影响 RAG/Agent 核心能力；只需知道它调用哪些 API |
| `frontend/node_modules/`、构建缓存 | 依赖生成物，不是项目核心代码 |
| `backend/finetuning/` | 属于后续模型训练实验，不是 MeetingMind 主链必需部分 |
| 历史优化记录和早期架构草案 | 用于了解演进，不必逐篇背诵 |
| `artifacts/` 下的本地运行产物 | 只看报告和 Manifest，不需要研究生成过程 |
| `backend/uploads/`、模型权重 | 本地运行数据/大文件，不纳入核心代码学习 |

## 六、面试时的项目边界
